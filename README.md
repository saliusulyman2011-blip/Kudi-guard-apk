# Kudi Guide 💰

Kudi (meaning "Money" in Hausa) is a lightweight personal finance tracker made for Nigerians.

No bank connection needed. Just track your money your way.

### Features
- Track daily income and expenses in Naira (₦)
- Visual spending history with bar charts
- Savings goal tracker
- Works offline
- 100% mobile-friendly & fast

### Why I Built This
I wanted a simple budgeting tool that understands the Nigerian context - no dollars, no complex setup. Just Kudi.

### Built With
- HTML, CSS, JavaScript
- Built entirely on mobile phone
